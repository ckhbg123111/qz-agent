# 单病种消息接口对接文档

## 说明
本文件描述当前项目中已经落地的单病种消息接口访问路径与联调说明。

- 原始协议定义以 `docs/单病种分诊系统V1.0.md` 为准
- 当前实现严格按该文档的消息字段命名、`Request/Response` 结构、`ACK_*` 事件类型进行建模
- 当前仅提供 HIS 推送到我方、我方返回 ACK 的消息接收接口
- 不提供查询类接口
- 病历提交接口本次未实现

## 协议约定
- 请求方式：`POST`
- Content-Type：`application/xml`
- 响应类型：`application/xml`
- 公共根节点：`<Request>` / `<Response>`
- 公共头节点：`<MessageHeader>`
- 公共体节点：`<MessageBody>`

### ACK 规则
推送类接口统一返回文档对应的 `ACK_*` 报文：

- 成功：`Result.Code=CA`
- 失败：`Result.Code=CE`
- 失败原因写入 `Result.Desc`

### 当前实现约束
- 当前版本重点是“收报文、基础校验、回 ACK”
- 当前只做了基础校验：`MessageHeader`、`MessageBody`、`EventType`、`MsgId`，以及挂号接口的 `EventTypeCode=REG`

## 已实现接口

### 1. 患者入出转推送(门诊)
- 对应章节：`患者入出转推送(门诊) ADT_A01_ADT_A01（MZ）`
- 项目路径：`/api/b2b/single-disease/patient/adt-a01-mz`
- 请求事件类型：`ADT_A01_MZ`
- 应答事件类型：`ACK_ADT_A01_MZ`
- 特殊说明：当前仅受理 `EventInfo.EventTypeCode=REG` 的挂号成功消息

### 2. 检查申请单推送（开立、作废）
- 对应章节：`检查申请单推送（开立、作废） ORM_O01_ORM_O01（NW、CA）`
- 项目路径：`/api/b2b/single-disease/check/orm-o01`
- 请求事件类型：`ORM^O01^ORM_O01`
- 应答事件类型：`ACK_ORM^O01^ORM_O01`

### 3. 检查预约推送

## 联调示例

### 请求头示例
```xml
<Request>
  <MessageHeader>
    <Sender>HIS</Sender>
    <Receiver>QZ_AGENT</Receiver>
    <SendTime>20260331103005</SendTime>
    <EventType>ADT_A01_MZ</EventType>
    <MsgId>TEST-20260331103005</MsgId>
  </MessageHeader>
  <MessageBody>
    <!-- 具体业务报文结构参照原始文档 -->
  </MessageBody>
</Request>
```

### 成功应答示例
```xml
<Response>
  <MessageHeader>
    <Sender>QZ_AGENT</Sender>
    <Receiver>HIS</Receiver>
    <SendTime>20260331103006</SendTime>
    <EventType>ACK_ADT_A01_MZ</EventType>
    <MsgId>TEST-20260331103005</MsgId>
  </MessageHeader>
  <MessageBody>
    <Result>
      <Code>CA</Code>
      <Desc></Desc>
    </Result>
  </MessageBody>
</Response>
```

### 失败应答示例
```xml
<Response>
  <MessageHeader>
    <Sender>QZ_AGENT</Sender>
    <Receiver>HIS</Receiver>
    <SendTime>20260331103006</SendTime>
    <EventType>ACK_ADT_A01_MZ</EventType>
    <MsgId>TEST-20260331103005</MsgId>
  </MessageHeader>
  <MessageBody>
    <Result>
      <Code>CE</Code>
      <Desc>EventType不匹配，期望值为ADT_A01_MZ</Desc>
    </Result>
  </MessageBody>
</Response>
```
