# 宣教智能体消息接口测试请求示例

## 1. 文档说明
本文档用于提供宣教智能体消息接口的手工联调请求示例，方便通过 Postman、Apifox 或 `curl` 直接调用测试。

说明如下：

- 本文档仅提供测试请求示例，不替代正式对接文档
- 示例报文以当前代码中的 XML 模型为准
- 字段值以“能手工联调、能用于接口冒烟测试”为目标构造
- 正式联调时，建议仍以 `docs/宣教智能体消息接口对接文档.md` 和原始协议文档为准

## 2. 通用调用方式

- 请求方式：`POST`
- 请求头：`Content-Type: application/xml`
- 鉴权：当前版本无需携带登录鉴权信息
- 接口前缀：`/api/b2b/sdhp`

调用地址示例：

```text
https://test.aiqikang.com:8082/api/b2b/sdhp/patient/adt-a01-mz
```

## 3. 使用建议

- 每次调用时建议替换 `MsgId`，保证唯一
- `MessageHeader.EventType` 必须与接口定义完全一致
- 返回虽然通常是 HTTP `200`，但仍需检查 XML 中的 `Result.Code`
- `Result.Code=CA` 表示成功，`Result.Code=CE` 表示失败
