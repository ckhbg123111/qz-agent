## 编码字段约定

为保证中国医院 HIS/EMR/LIS/药房系统对接稳定性，宣教推送规则涉及的关键业务对象统一采用“编码 + 名称”双字段：

- 病种/诊断：优先使用 `ICD-10`
- 检验项目：优先使用院内 `LIS` 项目编码
- 药品：优先使用院内药品字典编码
- 手术：优先使用 `ICD-9-CM3` 或院内手术编码

说明：

- 文档中的编码示例主要用于说明字段格式和推荐来源，生产环境应以医院主数据字典为准。
- 若医院已维护医保编码、区域互认编码，可作为扩展字段补充传入，但不替代院内主键编码。

## 接口字段补充定义

### 1. 病历确诊接口

- 接口路径：`/api/b2b/qz/hp/diagnosis-event`

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| diagnosisCode | String | 主诊断编码，优先传 `ICD-10` |
| diagnosisCodeSystem | String | 诊断编码体系，默认 `ICD-10` |
| diagnosis | String | 主诊断名称 |
| diseaseType | Enum | 平台内部病种枚举，用于宣教路由 |

推荐编码示例：

- 胃炎：`K29.50`
- 消化性溃疡：`K27.90`
- 十二指肠溃疡：`K26.90`
- 胃溃疡：`K25.90`
- 溃疡性结肠炎：`K51.90`
- 克罗恩病：`K50.90`
- 糖尿病：`E14.90`

### 2. 检验单开具接口

- 接口路径：`/api/b2b/qz/hp/lab-appointment`

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| diagnosisCode | String | 主诊断编码，优先传 `ICD-10`，糖尿病示例 `E14.90` |
| diagnosisCodeSystem | String | 诊断编码体系，默认 `ICD-10` |
| labItems | Array<Object> | 检验项目列表，优先按院内 `LIS` 编码识别 |
| labItems[].labItemCode | String | 检验项目编码，优先使用院内 `LIS` 项目编码 |
| labItems[].labItemName | String | 检验项目名称 |
| labItems[].labItemCodeSystem | String | 编码体系，默认院内 `LIS` 项目字典 |
| labItems[].specimenType | String | 标本类型 |
| labItems[].itemCategory | String | 项目分组 |

推荐编码示例：

- 空腹血糖：`GLU_FAST`
- 糖化血红蛋白：`HBA1C`
- `13C/14C` 呼气试验：`C13BT`

### 3. 处方开具接口

- 接口路径：`/api/b2b/qz/hp/prescription`

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| diagnosisCode | String | 主诊断编码，优先传 `ICD-10`，糖尿病示例 `E14.90` |
| diagnosisCodeSystem | String | 诊断编码体系，默认 `ICD-10` |
| medicines | Array<Object> | 药品列表，优先按院内药品字典编码识别 |
| medicines[].medicineCode | String | 药品编码，优先使用院内药品字典编码 |
| medicines[].medicineName | String | 药品名称 |
| medicines[].medicineCodeSystem | String | 编码体系，默认院内药品字典 |
| medicines[].specification | String | 规格 |
| medicines[].dosage | String | 单次剂量 |
| medicines[].dosageUnit | String | 剂量单位 |
| medicines[].frequency | String | 给药频次 |
| medicines[].route | String | 给药途径 |

推荐编码示例：

- 胰岛素：`DRUG_INSULIN_001`
- 利拉鲁肽：`DRUG_LIRAGLUTIDE_001`
- 司美格鲁肽：`DRUG_SEMAGLUTIDE_001`
- 替尔泊肽：`DRUG_TIRZEPATIDE_001`

### 4. 手术相关补充

以下两个接口本次补充手术编码字段，用于稳定识别肾穿刺、屈光手术等宣教规则：

- `办理入院` `/api/b2b/qz/surgery/admission`：新增 `plannedOperationList`
- `办理出院` `/api/b2b/qz/surgery/discharge`：新增 `performedOperationList`

子字段统一复用手术条目结构：

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| operationSeq | Integer | 手术序号 |
| operationCode | String | `ICD-9-CM3` 或院内手术编码 |
| operationName | String | 手术名称 |
| operationSite | String | 手术部位 |
| operationMethod | String | 手术方式/入路 |

推荐编码示例：

- 肾穿刺活检：`55.2300`
- 屈光手术：院内手术编码示例 `EYE_REFRACT_001`
